# Proposal

## Why

Проект сейчас содержит только `Main.java` с «Hello world!». Нужен небольшой, но полноценный продукт — менеджер списка задач, — чтобы на нём пройти полный цикл OpenSpec (propose → apply → archive) и затем развивать его следующими изменениями.

## What Changes

- Встроенный HTTP-сервер (`com.sun.net.httpserver.HttpServer` из JDK) на порту 8080, запускаемый из `Main`.
- REST API для задач: `GET /api/tasks`, `POST /api/tasks`, `PUT /api/tasks/{id}`, `DELETE /api/tasks/{id}` с обменом в JSON.
- Задача содержит `id`, `title`, `done`, `createdAt`.
- Валидация: пустой или состоящий из пробелов `title` отклоняется (`400`), обращение к несуществующей задаче возвращает `404`.
- Хранение задач в памяти процесса: после перезапуска список пуст.
- HTML-страница на `/`, которая показывает список задач и позволяет создавать, отмечать выполненными, переименовывать и удалять задачи.
- Новая зависимость: Gson для сериализации JSON.

Вне рамок этого изменения (кандидаты в следующие изменения): сохранение задач в файл, фильтры «все / активные / выполненные», аутентификация, несколько списков.

## Capabilities

### New Capabilities
- `task-management`: жизненный цикл задачи и HTTP API — создание, просмотр, изменение, удаление, правила валидации и коды ответов.
- `task-web-ui`: браузерная страница, через которую пользователь работает со списком задач поверх API.

## Impact

- **Код**: `src/main/java/org/example/` — переписывается `Main.java`, добавляются классы модели, хранилища и HTTP-обработчиков; новый ресурс `src/main/resources/static/index.html`.
- **Зависимости**: `pom.xml` — добавляется `com.google.code.gson:gson`, для тестов — JUnit 5; сборка исполняемого приложения (запуск через `exec:java` или аналог).
- **API**: новый HTTP-интерфейс на `localhost:8080`.
- **Системы**: внешних систем и базы данных нет.
