# Менеджер задач

Небольшое веб-приложение на Java 17 для ведения списка задач: HTTP API в формате JSON и браузерная страница поверх него. Задачи хранятся в памяти процесса — после перезапуска список пуст.

## Запуск

```bash
mvn compile exec:java
```

После запуска откройте http://localhost:8080/.

Порт задаётся переменной окружения `PORT` (по умолчанию `8080`). Из IntelliJ IDEA можно запустить класс `org.example.Main`.

Тесты:

```bash
mvn test
```

## API

Все ответы — `application/json; charset=utf-8`. Задача:

```json
{"id": 1, "title": "Купить молоко", "done": false, "createdAt": "2026-10-14T10:15:30.123Z"}
```

| Метод    | Путь              | Тело                              | Ответ                                   |
|----------|-------------------|-----------------------------------|-----------------------------------------|
| `GET`    | `/api/tasks`      | —                                 | `200`, массив задач в порядке создания  |
| `POST`   | `/api/tasks`      | `{"title": "..."}`                | `201`, созданная задача                 |
| `PUT`    | `/api/tasks/{id}` | `{"title": "..."}` и/или `{"done": true}` | `200`, обновлённая задача       |
| `DELETE` | `/api/tasks/{id}` | —                                 | `204` без тела                          |

`PUT` меняет только переданные поля. Пробелы по краям `title` обрезаются.

Ошибки возвращаются в виде `{"error": "<сообщение>"}`:

- `400` — пустой или отсутствующий `title`, `title` без единой буквы или цифры (например, `+` или `!!!`), некорректный JSON;
- `404` — задачи с таким `id` нет или `id` не число;
- `405` — метод не поддерживается для этого пути.

Пример:

```bash
curl -X POST http://localhost:8080/api/tasks -H "Content-Type: application/json" -d '{"title": "Купить молоко"}'
```
